Privacy Policy

Last updated: 29 October 2026

Vaibhav Stats is a personal tool used only by its owner to read the statistics of the owner's own YouTube channel and Instagram account.

What data it accesses

With the owner's permission, it reads the owner's own channel and video statistics through the YouTube Data API, the YouTube Analytics API and the Instagram API, using read-only access (for YouTube: the youtube.readonly and yt-analytics.readonly scopes). It does not access any other person's account or data.

How the data is used and stored

The statistics are saved only on the owner's own computer, to show how each video performed. Nothing is uploaded to any server, sold, shared with third parties or used for advertising.

Google user data

Vaibhav Stats' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google Account page (myaccount.google.com, Security, Third-party connections) and from Instagram (Settings, Apps and websites). Deleting the tool's local files removes all stored data.
